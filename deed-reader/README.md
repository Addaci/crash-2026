# Deed Reader

A browser tool for reading a notarial deed beside its scans: transcription with a record of help used, the machine text (HTR) with its provenance, translation and synthesis views, search across all layers, page notes and an entity table.

**Arrives 22 to 23 November 2026**, cleaned of all data, with:

- the reader itself (one HTML file, no installation);
- the builder that turns local index records, scans and HTR into the reader's data file;
- invented sample data, so the reader opens straight after cloning;
- notes on running it on the hackathon cluster (served from a job, opened through an SSH tunnel, saving to the team workspace, model calls logged).

The user guide will be in `docs/`.
